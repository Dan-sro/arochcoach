Page 1/5 — Parties 1 à 3 : répertoire courant, création, arborescence

etudiant@ubuntu: ~
# ── Partie 1 : ouvrir une console, où suis-je ? ──
etudiant@ubuntu:~$ pwd
/home/etudiant
# « pwd » affiche le répertoire courant : c'est le répertoire personnel (/home/etudiant).
# Au lancement du terminal, on s'y trouve déjà.
# ── Partie 2 : créer le répertoire « essai » ──
etudiant@ubuntu:~$ mkdir essai
etudiant@ubuntu:~$ ls
Bureau Documents essai Images Modèles Musique Public Téléchargements Vidéos
# ── Partie 3 : créer l'arborescence dans « essai » ──
etudiant@ubuntu:~$ cd essai
etudiant@ubuntu:~/essai$ mkdir rep1 rep2
etudiant@ubuntu:~/essai$ touch a b c d rep1/a1 rep1/b1 rep1/c1 rep2/a2 rep2/b2 rep2/c2
etudiant@ubuntu:~/essai$ tree
.
├── a
├── b
├── c
├── d
├── rep1
│ ├── a1
│ ├── b1
│ └── c1
└── rep2
├── a2
├── b2
└── c2
2 directories, 10 files
# mkdir = créer des dossiers · touch = créer des fichiers vides.
# Sans « tree » : sudo apt install tree, ou vérifier avec « ls -R ».

Page 2/5 — Parties 4 à 7 : écrire, afficher, recopier des fichiers

etudiant@ubuntu: ~/essai
# ── Partie 4 : 2 lignes dans a1 (depuis « essai », a1 = rep1/a1), puis afficher ──
etudiant@ubuntu:~/essai$ echo "Premiere ligne du fichier a1" > rep1/a1
etudiant@ubuntu:~/essai$ echo "Deuxieme ligne du fichier a1" >> rep1/a1
etudiant@ubuntu:~/essai$ cat rep1/a1
Premiere ligne du fichier a1
Deuxieme ligne du fichier a1
# « > » écrase/crée · « >> » ajoute à la suite · « cat » affiche.
# ── Partie 5 : aller dans rep2, ajouter 1 ligne à a1, afficher ──
etudiant@ubuntu:~/essai$ cd rep2
etudiant@ubuntu:~/essai/rep2$ echo "Troisieme ligne ajoutee depuis rep2" >> ../rep1/a1
etudiant@ubuntu:~/essai/rep2$ cat ../rep1/a1
Premiere ligne du fichier a1
Deuxieme ligne du fichier a1
Troisieme ligne ajoutee depuis rep2
# « .. » = dossier parent : depuis rep2, a1 s'écrit ../rep1/a1.
# ── Partie 6 : retour au répertoire personnel en UNE commande + créer « test » ──
etudiant@ubuntu:~/essai/rep2$ cd
etudiant@ubuntu:~$ pwd
/home/etudiant
etudiant@ubuntu:~$ mkdir test
# « cd » seul (ou « cd ~ ») ramène directement au répertoire personnel.
# ── Partie 7 : recopier SEULEMENT les fichiers de « essai » vers « test » ──
etudiant@ubuntu:~$ cp essai/a essai/b essai/c essai/d test/
etudiant@ubuntu:~$ tree test
test
├── a
├── b
├── c
└── d
0 directories, 4 files
# Sans -r : les dossiers rep1/rep2 ne sont PAS copiés, seulement les 4 fichiers.

Page 3/5 — Parties 8 à 11 : supprimer (-i, -I, -f), copie récursive

etudiant@ubuntu: ~
# ── Partie 8 : effacer les fichiers de test avec confirmation pour CHAQUE fichier ──
etudiant@ubuntu:~$ rm -i test/*
rm: supprimer le fichier vide 'test/a' ? y
rm: supprimer le fichier vide 'test/b' ? y
rm: supprimer le fichier vide 'test/c' ? y
rm: supprimer le fichier vide 'test/d' ? y
# -i (interactif) : demande « y » pour chaque fichier.
# ── Partie 9 : recréer puis effacer avec l'option -I ──
etudiant@ubuntu:~$ cp essai/a essai/b essai/c essai/d test/
etudiant@ubuntu:~$ rm -I test/*
rm: supprimer 4 arguments ? y
# -I : UNE seule confirmation quand il y a plus de 3 fichiers. Moins bavard que -i.
# ── Partie 10 : recréer puis effacer avec l'option -f ──
etudiant@ubuntu:~$ cp essai/a essai/b essai/c essai/d test/
etudiant@ubuntu:~$ rm -f test/*
etudiant@ubuntu:~$ ls test
# (aucun affichage : dossier vide, AUCUNE question posée)
# -f (force) : supprime sans demander, ignore les fichiers inexistants. Prudence !
# ── Partie 11 : recopier TOUT (fichiers + sous-dossiers) ──
etudiant@ubuntu:~$ cp -r essai/* test/
etudiant@ubuntu:~$ tree test
test
├── a
├── b
├── c
├── d
├── rep1
│ ├── a1
│ ├── b1
│ └── c1
└── rep2
├── a2
├── b2
└── c2
2 directories, 10 files
# -r (récursif) : copie aussi rep1 et rep2 avec leur contenu.

Page 4/5 — Parties 12 à 16 : vider, déplacer, chemins relatifs

etudiant@ubuntu: ~
# ── Partie 12 : vider « test » SANS supprimer le dossier ──
etudiant@ubuntu:~$ rm -rf test/*
etudiant@ubuntu:~$ ls test
# (vide) : le contenu a disparu, mais « test » existe toujours.
# ── Partie 13 : refaire la partie 11, puis supprimer « test » ET son contenu ──
etudiant@ubuntu:~$ cp -r essai/* test/
etudiant@ubuntu:~$ rm -rf test
etudiant@ubuntu:~$ ls
Bureau Documents essai Images Modèles Musique Public Téléchargements Vidéos
# « test » a disparu : -r = dossiers inclus, -f = sans confirmation.
# ── Partie 14 : recréer « test » et DÉPLACER tout le contenu de « essai » ──
etudiant@ubuntu:~$ mkdir test
etudiant@ubuntu:~$ mv essai/* test/
etudiant@ubuntu:~$ ls essai
# (vide) : « mv » DÉPLACE — « essai » est maintenant vide, tout est dans « test ».
# Le schéma du sujet montre l'état AVANT (essai plein) et APRÈS (test plein).
# ── Partie 15 : aller dans test/rep1, créer « rep2sub » dans rep2 ──
etudiant@ubuntu:~$ cd test/rep1
etudiant@ubuntu:~/test/rep1$ mkdir ../rep2/rep2sub
etudiant@ubuntu:~/test/rep1$ ls ../rep2
a2 b2 c2 rep2sub
# ── Partie 16 : toujours dans test/rep1, déplacer le fichier « a » dans rep2sub ──
etudiant@ubuntu:~/test/rep1$ mv ../a ../rep2/rep2sub/
etudiant@ubuntu:~/test/rep1$ tree ~/test
/home/etudiant/test
├── b
├── c
├── d
├── rep1
│ ├── a1
│ ├── b1
│ └── c1
└── rep2
├── a2
├── b2
├── c2
└── rep2sub
└── a
3 directories, 10 files
# Depuis test/rep1 : « a » = ../a · « rep2sub » = ../rep2/rep2sub/.
etudiant@ubuntu:~/test/rep1$ echo "TP terminé"
TP terminé
etudiant@ubuntu:~/test/rep1$

Page 5/5 — Aide-mémoire des commandes Linux

etudiant@ubuntu: ~
etudiant@ubuntu:~$ cat aide-memoire.txt
┌─────────────────┬───────────────────────────────────────────────┐
│ COMMANDE │ RÔLE │
├─────────────────┼───────────────────────────────────────────────┤
│ pwd │ afficher le répertoire courant │
│ cd [dossier] │ se déplacer (cd seul = retour personnel) │
│ ls │ lister le contenu d'un dossier │
│ mkdir nom │ créer un répertoire │
│ touch nom │ créer un fichier vide │
│ echo "..." > f │ écrire dans un fichier (écrase) │
│ echo "..." >> f │ ajouter à la fin du fichier │
│ cat fichier │ afficher le contenu d'un fichier │
│ cp src dest │ copier (ajouter -r pour les dossiers) │
│ mv src dest │ déplacer / renommer │
│ rm cible │ supprimer (-r dossiers, -f force, -i demande) │
│ tree │ afficher l'arborescence (apt install tree) │
└─────────────────┴───────────────────────────────────────────────┘
Rappels : « . » = ici · « .. » = parent · « ~ » = personnel · « * » = tout.
Options rm : -i = demande à chaque fois · -I = une fois si > 3 fichiers · -f = jamais.
